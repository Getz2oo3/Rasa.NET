Map context 1430 / client 1.16.5.0

Scope
NPC and mob population. Quests, mission progression, escort events and fabricated
population density are outside this pass. Existing Pravus rows remain intact.
Historical evidence of a population is not proof of an exact spawn coordinate.

Presentation and runtime defaults
Species is historical: Nylla is Forean, Price and Perkins are Human.
Appearance uses existing stock Forean ranger (class 7034) and male AFS officer
(class 3846) templates. Exact original outfits, colors, facing and statistics
have NOT been recovered. Level 10 / 1000 HP and a 2-second respawn use existing
mission-NPC conventions; spawnpool.respown_time is in tenths of a second.
These stationary, friendly actors have no attacks, no greeting and no NPC
mission package. They do not offer quests or trigger story events.

Do not present these template appearances or runtime defaults as recovered
retail data. This first patch validates historical placement and client names.

Group centers and approximate counts are insufficient to invent individual
placement coordinates, patrol routes or wave timers. Validate the room/floor
and obtain additional evidence before placing these enemies.

Validation and deployment
Run the PravusPopulationTests regression filter. It uses a disposable SQLite
World database to check upgrade, repeated update, rollback, floor heights,
existing population preservation and unchanged mission-definition counts.
The MySQL check generates forward and rollback SQL without a database connection.
Live MySQL execution is separate from local SQLite testing.
Validated locally on 2026-10-20: the SQLite upgrade/rollback test passed;
the offline MySQL check plus StandingSpawnHeightTests and
SpawnPoolLifecycleTests passed (46 tests). Isolated build outputs were used,
with no changes to the running server or its databases during those tests.
Subsequent user testing on 2026-10-20 confirmed Nylla, Price and Perkins at
their locations in the running client. Displayed names are also confirmed
by the supplied screenshots. Exact historical appearance, detailed ground
contact, absence of quest interactions and squad-instance isolation were
not independently established by those screenshots.

For the local Windows installation: stop Game and Auth using their console
exit commands, use Local Server/Build Server.cmd, then start Auth and Game.
SQLite applies the new World migration on startup; no database reset is needed.
Never delete character databases to install population updates.

Enter Pravus with /gotomap 1430 and inspect each location. Use .where and .near
to report position and entities. Confirm visible feet, model, name, no quest
offers, and isolation from another squad's instance. The first patch is not
an assertion that the whole operation is restored.
